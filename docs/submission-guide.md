# Project 2 Submission Guide

Use this guide with `submission-manifest.csv` when you submit in Brightspace.

## Submit in Brightspace

1. Submit the repository URL: <https://github.com/Loganritter1/Project-2>.
2. Submit the three unlisted YouTube URLs from the manifest:
   - Video 1: <https://youtu.be/9__EBhFYibU>
   - Video 2: <https://youtu.be/RwayiSQbVro>
   - Video 3: <https://youtu.be/eaCGOtweKmE>
3. Attach `decision-memo.md` and `validation-and-ai-use.md`, exactly as they appear in `docs/`.
4. Attach `submission-manifest.csv` and the three transcript files if the Brightspace form permits additional attachments. The files are also linked in the repository and manifest.

Do not submit local MP4 files. The required video submissions are the three YouTube links.

## Required repository contents

The repository contains the runnable app, dependencies, source code, frozen input data, tests, validation runner, visible output, data card, cold-run record, decision memo, validation-and-AI-use record, submission manifest, and three corrected transcripts.

## Final checks before clicking Submit

- Push the final commit and confirm the repository is accessible to the instructional team.
- Open each unlisted video while logged out or in a private window.
- Enable YouTube captions and correct substantive terms, ticker symbols, names, attribution, and material numbers.
- Confirm the app starts from the README and that `python run_validation.py` produces the visible output.
- Confirm no credentials, `.env` file, raw video files, or local `_video_review/` folder are committed.
- Confirm Brightspace contains the repository URL, all three YouTube URLs, and the two required Markdown attachments.

Do not submit Edition A, Edition B, or a Research-Evolution PDF for Project 2. The project checklist explicitly says to skip the Before-AI and research-evolution items.
